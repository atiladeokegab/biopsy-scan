# Preflight METABRIC external validation

Protocol `preflight-metabric-external-v2`, specified 2026-11-23. The geometry and event floors were fixed before computing the count gate. Hermes records the reviewed protocol and split before the pilot analysis, and the pilot checkpoint before authorizing the reserved analysis.

## Question

Does the imaging plan Preflight prefers in pilot patients preserve a prespecified spatial biomarker's disease-specific survival association better in reserved patients? The test uses archived breast tumour imaging from the METABRIC cohort and simulates two ways to allocate the same nominal imaging area.

## Endpoint and biomarker

The primary endpoint is disease-specific survival in `IMCClinical.csv`. Join one record per `metabric_id`. Use the recorded `yearsToStatus` in years, with `DeathBreast=1` as an event and `DeathBreast=0` as censored. Require finite positive follow-up, a binary event flag and `ERStatus` equal to `pos` or `neg`. Use ER status as the baseline-hazard stratum throughout.

The primary biomarker is the fraction of visible neighbours within a Euclidean radius of 50 µm that are T cells, averaged equally over visible invasive tumour epithelial focal cells in the patient’s selected image. Exclude the focal cell itself. Focal cells satisfy `is_epithelial=1`, `is_tumour=1`, `is_normal=0` and `is_dcis=0`. Classify only trimmed `cellPhenotype` values `CD4^{+} T cells` and `CD8^{+} T cells` as T cells. Other processed cells, including mixed and other annotated T-cell phenotypes, can contribute to the denominator. Give a focal cell with no visible neighbours a fraction of zero. Mark a patient with no visible focal cells as missing. Set classification perturbation to zero. Compute the mean and population standard deviation across all eligible pilot patients' full-image biomarker values. Require a finite, positive standard deviation. Freeze and reuse this scale for all designs, block deletions and the reserved partition.

- **B** samples 45 patients with one square of side 300√2 µm per patient.

## Analysis and decision

Within each partition, fit a single-feature Cox proportional hazards model with separate positive and negative ER baseline hazards and one common slope, using Breslow ties. Use full observed images for the dense reference and identical fit rules for both acquisition arms. Use complete cases, the frozen pilot scale and observed clinical outcomes. Report log hazard ratio per pilot standard deviation and a Wald 95% interval for the dense reference. Require at least ten complete-case events for the dense reference and five for each arm, a finite converged slope and finite positive variance. Track the total patients and events in each fit, crop attrition and all fit failures. Use a pair only if both arms can be fitted. Require at least 140 valid pairs in the full partition and for each deletion estimate to be used in patient-level uncertainty.

For each valid pair compute `|logHR_A − logHR_dense| − |logHR_B − logHR_dense|`. Report the mean, the failed-pair proportion and a percentile 95% interval from 2,000 resamples of the paired differences. Seed with PCG64 and `SeedSequence([20261123, partition_code, 200])`. This interval quantifies repeated acquisition uncertainty conditional on the cohort.

For patient-level uncertainty, omit each block from the dense reference and both arms. Filter the original permutation and refill the arms, retaining the original crop values. Keep the pilot scale fixed. With ten leave-block-out means, compute the delete-group jackknife standard error as the square root of 9/10 times the sum of squared deviations from their mean. Report the full estimate plus or minus 2.262 standard errors as an approximate 95% patient-level interval. Report all ten block estimates. If a deletion fails the fit requirements, mark the patient-level interval unavailable.

The pilot recommends A when the mean is below zero and B when it is above zero. A tie, unusable dense reference or fewer than 140 usable pairs yields no pilot recommendation and ends the experiment before opening. The reserved result supports the recommendation when its mean matches the pilot direction, both reserved uncertainty intervals exclude zero in that direction and the reserved dense reference's 95% interval excludes zero. Report a contrary point estimate with its uncertainty when the reserved mean favours the other arm. Treat insufficient fits or unavailable or inconclusive intervals as insufficient evidence. The resulting evidence concerns retrospective acquisition comparisons for this selected cohort and phenotype. A lab's own planning baseline and decision to change imaging remain unmeasured.
