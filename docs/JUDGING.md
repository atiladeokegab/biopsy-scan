# Preflight against the four judging criteria

Every number below is copied from a committed results file. Where that file is on an open PR, the row names the PR. Labels:
- **MEASURED**: a committed results file from a real run.
- **TESTED**: a passing test in `make smoke`.
- **ESTIMATE**: a simulated rate (power, false alarms or calls over many studies, with its interval) or arithmetic on measured rows; not a direct measurement.
- **SYNTHETIC**: outcomes or data generated by a model, not observed.
- **ANALYTIC**: a closed-form formula.
- **UNMEASURED**: a run exists but cannot answer the question (for example underpowered).
- **PENDING**: not built or not run yet. A row whose evidence sits on an open PR names the PR.

All real-data results are exploratory: the outcomes have already been seen.

The rung-0 row and the CPU-ladder row cover different scopes, so their ratio is not quoted as a speed-up (`lab_today.comparison_scope`); the matched workflow comparison (#123) times both procedures through scoring, under the exclusions in its row. R-14 fits a full model per candidate, whereas the R-15 screen computes a score test. The R-14 comparison is therefore a workflow comparison, not an equal-work speed-up (PRD principle 5).

To rerun the race on your own CPU: `make race-local` (#140; it fetches the Zenodo data first through `make data`). It runs the same lab and fused arms as #113 and #120 on a small slice, 8 studies per stream on every core by default (`make race-local RACE_STUDIES=20 RACE_WORKERS=4` to change). Its timings are MEASURED on that machine, not the Modal figures, and it times the work without reproducing the decisions.
